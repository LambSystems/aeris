# Aeirs UI (Legacy Experiment)

This folder is an older Next.js UI experiment. It is intentionally kept for provenance, but it is not the maintained portfolio runtime.

Use these paths instead:

- Primary live app: `backend/streamlit_app.py`
- Backend/API: `backend/app/`
- Optional maintained React shell: `ui/`

The folder name is also misspelled (`aeirs-ui` instead of `aeris-ui`), so reviewers should treat it as archived hackathon iteration unless a future cleanup moves it under an explicit archive directory.
