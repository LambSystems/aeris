# Aeris UI Scratch Workspace

This folder is a scratch/legacy UI workspace kept for project history. It is not the maintained portfolio runtime.

Use these paths instead:

- Primary live app: `backend/streamlit_app.py`
- Backend/API: `backend/app/`
- Optional maintained React shell: `ui/`

The space in this folder name makes it awkward for tooling, so a future cleanup should move it under an explicit archive directory or remove it after confirming no unique work remains.
